# Design canvas working files

The published canvas lives at
<https://claude.ai/code/artifact/815e27bd-4acd-4970-ae88-e431f5e1f85a>.

These `.dc.html` files are the source of the six artboards; `canvas.json` is the layout.
Every value in them is lifted from `app/globals.css` — if the design system changes there,
change it here too, then re-seed and republish to the same URL.

Artboards: home hero, comparison template, night CTA band, design system sheet,
and the 390px home and pricing views.

The seeded `here-design-system.html` is a build output (~2 MB) and is gitignored.
